# Support

Current builds are unsupported pre-alpha tests. GitHub Issues are appropriate
for reproducible bugs. If GitHub Discussions are enabled, use them for setup
questions, ideas, and general help. Suspected vulnerabilities belong only in
[private vulnerability reporting](SECURITY.md).

Useful bug reports include the Yappa version/commit, client OS and desktop
environment, server platform and installation method, reproduction steps,
expected/actual behavior, whether restart changes the result, and minimal
sanitized logs. Redact screenshots.

Never upload passwords, bearer tokens, encryption or signing keys, private
messages/attachments, production databases, private hostnames/IPs, server
credentials, or other people's personal information.
