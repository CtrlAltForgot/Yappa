# Roadmap

This roadmap separates active release work from research and possible ideas.
It intentionally assigns no dates.

## Pre-alpha stabilization — committed direction

- Resolve friend-test blockers and preserve reliable history/session recovery.
- Complete native multi-client voice, camera, screen-share, and encryption
  validation across target platforms and realistic networks.
- Keep server packaging, migration, backup, restore, and deployment evidence
  synchronized with client/backend contracts.
- Improve contributor and release discipline without widening security claims.

## Alpha — committed direction, scope subject to evidence

- Publish clearly versioned, signed where available, reproducible test builds.
- Establish supported installation/upgrade paths and compatibility policy.
- Complete durable encrypted communication and recovery acceptance gates.
- Validate accessibility and primary desktop workflows with more testers.

## Beta — planned phase

- Stabilize public APIs, migrations, error recovery, and cross-version behavior.
- Broaden platform/network compatibility and operational monitoring guidance.
- Close product-quality gaps discovered during alpha testing.

## Security review and hardening — required before strong claims

- Commission independent architecture, protocol, and implementation review.
- Complete message/media inspection, vector, downgrade, and device-lifecycle gates.
- Remediate findings and publish precise claims and threat boundaries.

## Broader platform support — research

- Determine supported macOS and additional Linux desktop combinations.
- Evaluate Windows server lifecycle support through the canonical workload.
- Consider other client form factors only after desktop contracts stabilize.

## Long-term ideas — possible, not committed

- Integrated threads, cross-server identity/direct messages, calendar, shared
  music, and durable hosted file sharing.
- These ideas require separate product, privacy, protocol, licensing,
  authorization, migration, and deployment designs before implementation.
