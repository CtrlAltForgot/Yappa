# Client Installation

Yappa publishes unsigned pre-alpha test builds through
[GitHub Releases](https://github.com/CtrlAltForgot/Yappa/releases). Current
public pretest artifacts target Linux x64 and Windows x64. Review the release
notes, checksum/evidence files, [project status](../PROJECT_STATUS.md), and
[known limitations](../KNOWN_LIMITATIONS.md) before using a build.

There is no supported installer or automatic updater yet. Extract the archive,
keep its files together, and run the executable for your platform. Operating
systems may warn because builds are not signed. Do not bypass organization
security policy to run Yappa.

For source builds, use the [client README](../../client/README.md). For
connection problems, see [troubleshooting](../troubleshooting/TROUBLESHOOTING.md).
