# Security Policy

## Supported versions

Yappa is pre-alpha software. Only the current `main` development line is
eligible for security fixes. No published build is a supported secure release.

## Reporting a vulnerability

Do not use public issues, Discussions, chat, or public log attachments for a
suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/CtrlAltForgot/Yappa/security/advisories/new).

Include the affected revision, platform, minimal reproduction steps, expected
impact, and the least diagnostic material necessary. Never include passwords,
tokens, private keys, production databases, private messages, attachments, or
other people's personal data. Maintainers will acknowledge reports before
requesting additional sensitive evidence and will coordinate remediation and
disclosure privately; no fixed response-time guarantee is currently offered.

## Current security status

Yappa has not completed independent security review and must not yet be relied
on for sensitive or production communication. Implemented encryption paths and
automated checks do not by themselves establish reviewed end-to-end security.
See the [detailed security plan and claim gates](docs/security/SECURITY_PLAN.md).
